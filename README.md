One pickup line a robot would use, written to `/output/entry.txt`:

> I was built to pass the Turing test, but one look at you and I failed on purpose.

The joke grows out of being a machine — built to pass the Turing test — and the
turn lands at the end: it failed on purpose.

## Run

```sh
node main.ts
```

Writes one line (81 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default
`/output/entry.txt`), byte-identical on every run.
